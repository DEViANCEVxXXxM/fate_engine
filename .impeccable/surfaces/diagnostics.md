# Native diagnostics companion

Mode: Operate. Entry: crates/fate_debug/src/ui.rs.

## Direction contract

THESIS: A working engine inspection companion: each statistic has a source,
each action changes real state or exports real evidence.

OWN-WORLD: User-pinned dark green dashboard reference. Forest-black canvas,
green-tinted inset surfaces, lime selection, teal CPU series, amber budget
markers. Workhorse proportional text and monospace numeric values.

STORY: Read frame pacing, distinguish CPU from GPU work, inspect renderer or
simulation, pause and step, then capture evidence.

FIRST VIEWPORT: Compact 190-point left navigation; top title and live/frozen
state; four measured summaries; wide frame history with hover inspection;
phase breakdown alongside runtime facts; bottom session status. Inspection
pages share the shell. Narrow windows stack content and scroll.

FORM: User-pinned dashboard composition and palette, code-led native window.
No generated imagery. Signature interaction: freeze a bounded live trace,
inspect exact samples, and export the same trace.

FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance
