# Documentation

This directory is the single source of truth for project documentation.

| Document | Purpose | Status |
|---|---|---|
| [engine-guide.md](engine-guide.md) | How to build, consume, and use the current engine APIs | Describes implemented behavior |
| [roadmap.md](roadmap.md) | Current capabilities, known gaps, and prioritized backlog | Updated working document |
| [engine-design.md](engine-design.md) | Technical design draft and architectural hypotheses | Draft; implementation status is governed by the guide and roadmap |
| [game-design.md](game-design.md) | Game-design draft for the target co-op FPS | Draft |
| [archive/](archive/) | Superseded drafts kept for history | Not authoritative |

When documents disagree, the order of authority is:

1. The code and its tests.
2. [engine-guide.md](engine-guide.md) and [roadmap.md](roadmap.md).
3. The design drafts.

The design documents intentionally describe target direction, not a promise
that a feature exists. Check the roadmap before treating a design item as
implemented.
